# Kseniia Bolshakova — personal website

Static personal website in English, designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files and the `assets` folder from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.

No framework, package manager, or build step is required.

## Included

- `index.html` — full site
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `assets/portrait.jpg` — author portrait extracted from the supplied CV
- `cv.pdf` — downloadable CV
- `book-proposal.pdf` — downloadable book proposal
